​MercilessZero v17 — концептуальный проект автономного высокопроизводительного кибердека (портативного микрокомпьютера), разработанный для аудита беспроводных сетей, радиочастотного мониторинга и аппаратного тестирования систем безопасности.

### ​Основные технические особенности этого проекта включают:

​Мобильная ARM-архитектура на базе SoC Raspberry Pi 3 Model B+. Обеспечивает стопроцентную совместимость с Linux-дистрибутивами (Kali Linux, Parrot OS), низкое энергопотребление и максимальную автономность "в поле"

​Архитектура​ корпус и материалы: Кастомное шасси повышенной прочности, выполненное из комбинации листового авиационного алюминия и углеволокна (карбона). Внутренний контур экранирован медным слоем для защиты от внешних ЭМИ-наводок (эффект клетки Фарадея).

​Система хранения: Использование SSD-картриджей для быстрой смены операционных систем или баз данных

​Связь и перехват: Выносные высокочастотные SMA-разъёмы для подключения узконаправленных и всенаправленных антенн. Поддержка внешних чипсетов с режимом мониторинга (Monitor Mode) и пакетной инъекции.
